## Présentation du projet

Le projet consiste à développer un site internet pour une ressourcerie afin de faciliter la gestion des dons, des ateliers, des inscriptions, des permanences et des horaires.

- **Anaïs Belhocine** : conception et gestion de la base de données (BDD).
- **Brayan Mbe Perol** : développement du back-end.
- **Jacques Opalaga** : participation à la base de données (BDD).

## Organisation technique

Le projet comprend trois parties principales :

- **Front-end** : interface utilisateur et pages de l'application.
- **Back-end** : traitement des demandes et communication avec la base de données.
- **Base de données** : stockage et organisation des informations, gestion des relations entre les tables, sécurité des accès et requêtes SQL.

Le groupe utilise GitHub pour partager le code source et suivre les modifications apportées au projet.
